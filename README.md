# 모심

**팀 모심** · 현대자동차그룹 차량용 앱 개발 공모전(Code your App into Pleos App Market) 출품작

> 거동이 불편한 동승자를 차가 알아보고, 그 자리의 승하차를 좌석·조명·음성으로 돕는 Pleos Connect 앱입니다.

문이 열리고 그 자리에 앉기까지 오래 걸리는 일이 같은 장소에서 되풀이되면 "부모님"으로 기억합니다. 다음부터는 보호자가 운전석에서 내리는 순간 지난번에 타신 자리를 미리 뒤로 빼고 등받이를 젖혀 둡니다. 어두우면 문이 열린 자리의 독서등을 켜고, 도착하기 전에 한 문장으로 안내합니다.

- APK: [`apk/모심_모심_release.apk`](apk/)
- 시연 영상: [`demo/모심_시연영상.mp4`](demo/모심_시연영상.mp4) (Pleos Connect 에뮬레이터 녹화). 장면별 스크린샷은 [`demo/screenshots/`](demo/screenshots/)에 있습니다.
  - 기다리는 구간과 타고 내리는 구간은 빨리 감았고, 빨리 감은 구간에는 화면 구석에 실제 걸린 초를 표시했습니다. 차량 상태는 Virtual Console로 조작했고, 마지막 컷(두 달 뒤 이동 변화)은 예시 탑승 기록을 넣어 보여 줍니다.

## 실행 방법

```bash
adb install -r --user 10 apk/모심_모심_release.apk     # 또는 소스에서: ./gradlew installDebug
adb shell am start --user 10 -n dev.gwanho.pleossample/.MainActivity
adb logcat -s CARE                                       # 앱 판정·SDK 호출 로그
```

처음 실행하면 위치 권한(`FUSED_LOCATION`)을 묻습니다. 거부해도 장소 조건과 도착 안내만 빠지고 나머지 기능은 동작합니다.

소스에서 빌드하려면 JDK 17이 필요합니다(Android Studio 내장 JBR 사용 가능).

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew :app:assembleRelease        # app/build/outputs/apk/release/모심_모심_release.apk
./gradlew :app:testDebugUnitTest      # 엔진·UiState 단위 테스트
```

### 시연 재현

`scripts/demo.sh`가 Virtual Console HTTP API로 시연 영상의 컷 2~12를 그대로 재현합니다. 앱 데이터를 지우고 처음 실행부터 시작하며, 화면 버튼은 글자를 찾아 자동으로 누릅니다. 약 6분 30초 걸립니다.

```bash
adb forward tcp:8088 tcp:8088
scripts/demo.sh                      # 컷 2~12 재현
SNAP=shots scripts/demo.sh           # 장면마다 앱 화면을 shots/NN-이름.png 로 저장
```

데모용 인자로 시트 앞뒤 이동 상한 1초(`moveLimitMs`, VC 50 눈금), 「곧 움직여요」 4.5초(`announceDelayMs`), 「됐어요」 6초(`doneMs`)를 씁니다. 에뮬레이터 시계는 `cmd alarm set-time`으로 이야기 날짜(화요일 오후 2시 30분, 해 진 저녁, 두 달 뒤)에 맞추고 끝에 되돌립니다. 시계를 바꾼 뒤에는 에뮬레이터 내비 서비스가 경로를 만들지 못하는 상태에 빠질 수 있으니, 내비가 필요하면 콜드 부트를 다시 하십시오. 데모는 내비 경로를 요청하지 않으므로 「곧 도착」 띠에는 글자만 나옵니다.

컷 순서(괄호는 시연 영상의 시각):

2. (0:40) 처음 실행 → 「크게 보기」 신호 카드 → 「소리 들려 드리기」 → 「시작하기」
3. (0:58) 1주째: 보호자가 내려 조수석 문을 열고 34초 뒤 착좌 → 「알아보는 중 1/2」. 짐 싣기(착좌 없이 닫힘)는 세지 않음
4. (1:18) 2주째: 같은 순서 → 2번째 착좌에 「부모님이 타실 때 오래 걸렸어요… 기억할까요?」, 보호자 복귀 때 팝업 → 「기억하기」. 며칠 뒤 처음 가는 식당에서 문이 열리면 자리를 넓히고(기다려 주세요 → 됐어요), 빨리 앉으면 「부모님 타셨어요?」 → 「아니요」(넓힌 자리의 원위치는 녹화 밖)
5. (1:55) 3주째: 보호자가 내리면 지난번 자리(조수석)를 뒤로 빼고 등받이를 젖힘(기다려 주세요 → 됐어요). 됐어요가 떠 있는 동안 문이 열리면 처음 한 번 신호 설명, 앉으면 열선(실내 온도 20℃ 미만 = 추움)
6. (2:25) 벨트를 매고 문이 닫히면 「등받이를 세울게요. 출발은 '딩동' 뒤에」 → 등받이·앞뒤 복귀 → 「딩동」 뒤 D, 멀리 감
7. (2:50) 주행 중 알아본 곳 200m 안: 「곧 도착해요」 띠 → P: 「문은 '딩동' 뒤에」 → 등받이·높이·쿠션 기울기·뒤로 → 「문을 열어 드릴 때까지 앉아 계세요」
8. (3:15) 벨트를 풀면 「다리를 하나씩 내놓고…」 → 내린 뒤 보호자가 운전석에 돌아오면 조수석 원위치
9. (3:35) 치료 뒤(보호자가 내려 조수석이 준비되는 구간은 녹화 밖): 2열 오른쪽 문이 열려 그 자리를 넓힘(조수석은 그대로)
10. (3:50) 등받이를 세우는 중(펄스가 쉬는 0.6초 안)에 D → 그 자리에서 멈추고 띠 「출발해서 자리 맞추기를 멈췄어요」
11. (4:05) 해 진 뒤(로우빔 켬) 집 앞 P에서 끊긴 자세를 이어서 내릴 때 자세까지 맞추는 구간은 녹화 밖 → 뒷문이 열리면 독서등 → 보호자 복귀 때 원위치
12. (4:25) 두 달 뒤(예시 기록 주입): 「지난달보다 내리실 때 평균 8초 더 걸렸어요」 → 좌석 길게 눌러 자세 맞추기 → 「이대로 기억」

## 테스트 환경과 필요 설정

- **개발에 사용한 에뮬레이터: Pleos Connect v2.1.0** (Android Automotive, API 34), **화면 2560×1440 @160dpi**. 콜드 부트가 필요하고, 현재 사용자는 10입니다.
- Vehicle SDK 2.3.2, TextToSpeech 3.3.1 (ON_DEVICE, ko-KR), FusedLocation 1.1.3
- 권한(Manifest 선언): `CAR_DOORS`, `CAR_DRIVE`, `CAR_SEATS`, `CONTROL_CAR_SEATS`, `CAR_LIGHTS`, `CONTROL_CAR_LIGHTS`, `CAR_CLIMATE`, `CONTROL_CAR_CLIMATE`, `CAR_SAFETY`, `PRIVATE_CAR_SAFETY`, `NAVI_ROUTE`, `NAVI_ROUTE_SEARCH`, `TTS_SERVICE`, `FUSED_LOCATION`(런타임)
- Virtual Console: `adb forward tcp:8088 tcp:8088` 후 `http://127.0.0.1:8088/`. 위치는 VC 에 없어 `adb emu geo fix <lon> <lat>` 로 주입합니다.
- 에뮬레이터 특성 보정: 좌석 착좌 값이 VC 와 반대로 오므로 화면의 "착좌 극성 반전" 스위치가 기본 켜짐입니다(실차에서는 끔). 가상 콘솔이 시트 위치를 시뮬레이션하지만 SDK 읽기는 0만 돌려주므로 이동은 성공 콜백과 VC 값으로 확인하고 정지는 시간 상한으로 처리합니다.
- 에뮬레이터 대체: 벨트 = 텔테일(`PUT /vehicle/telltales/simulator?type=SeatBelt&state=On|Off`, 켜짐 = 풂), 추움 = 목표 온도(현재 온도 입력이 없음), 어두움 = 전조등 로우빔(`PUT /vehicle/lights?headlamp_mode=LowBeam`), 내비 = NaviHelper 목적지 정보(경로가 있으면 5초마다 남은 거리·시간이 오고, 경로가 없으면 띠에 넣지 않음. 데모는 경로를 요청하지 않음). 시트 메모리 capability 는 빈 맵이라 자세 맞추기의 메모리 버튼은 꺼져 있습니다.
- 주행 중(기어≠P)에는 SDK 가 시트 명령을 거부합니다(50001). STOP 도 거부되므로 주행 중에 끊긴 이동은 멈추지 못하고 계획한 상한까지 간 것으로 보고, 다음 P 에서 STOP 을 한 번 더 보낸 뒤 원위치·내릴 때 자세를 이어갑니다.
- 데모 기준값: 뒷문 열림→착좌 20초 이상 × 2회, 장소 반경 200m, 소등 지연 10초. 실사용 권장값은 60초 × 3회.

엔진 규칙 요약

- 좌석·축: `Seat {PASSENGER, REAR_LEFT, REAR_RIGHT}` × `Axis {SLIDE, BACKREST, HEIGHT, TILT}`. 프로필은 「부모님」 하나(자리별 학습 횟수를 합산). 모든 이동은 P에서만, `capable(seat, axis)` 가 true 인 축만
- 학습: 문 열림→그 자리 착좌 Δt ≥ 기준이면 그 자리 카운터 +1. 착좌 없이 닫히면 짐 싣기로 제외. 첫 학습 위치를 장소로 기억하고 반경 밖은 세지 않음. 합이 기준 횟수에 닿으면 TTS 로 묻고 보호자가 화면에서 「기억하기」(opt-in). 「아니요」면 처음부터, 기억은 언제든 가능
- 준비: P + 운전석 착좌 OFF + 운전석 문 열림 → 지난번에 탄 자리 하나를 SLIDE BACKWARD, 이어서 BACKREST BACKWARD 0.4초(펄스). 탄 기록이 없으면 문이 열릴 때. 문이 열린 자리가 비어 있고 아직 안 넓혔으면 같은 준비
- 문 규칙(9.5): 열린 자리는 넓히는 쪽으로만, 착좌 ON 이면 그 자리 즉시 STOP. P 해제·시간 상한(3초)에도 STOP
- 가는 동안 자세(F14): 착좌 + 문 닫힘 + P → TTS + 독서등으로 예고 → 3초 뒤 등받이 FORWARD 를 400ms 이동/600ms 멈춤으로 끊어 1.2초, 이어서 타느라 물러난 앞뒤를 같은 펄스로 원래 자리까지(뒤로 빼 둔 채 달리지 않음). 예고 중이나 이동 중 문 열림·착좌 해제면 즉시 멈추고 남은 단계는 하지 않음. P 해제면 STOP 도 거부되어 움직이던 축은 상한까지 간 것으로 보고, 다음 P 에서 STOP 을 한 번 더 보낸 뒤 원위치·내릴 때 자세를 이어감
- 내릴 때 자세(F15): 주행 뒤 P 진입 + 착좌 → 같은 예고 뒤 등받이 FORWARD 0.8초 → 높이 → 쿠션 기울기, 이어서 앞뒤를 넓히는 쪽으로(앉은 사람 자신에게는 끼임 없음. 조수석 뒤로는 뒷자리가 비어 있을 때만)
- 원위치: 실제로 움직인 시간만큼 반대 방향으로, 앞뒤 → 등받이 → 높이 → 쿠션 기울기 순. 비어 있고 문이 닫힌 자리를 보호자가 운전석에 앉아 문을 닫았을 때(P)만. 보호자가 밖에 있는 동안 내렸으면 돌아올 때, 그 전에 출발했으면 다음 P 에서
- 조명: 어두울 때(로우빔 켜짐)만 확정 뒤 문 열림·예고·자세 이동 동안 독서등 ON, 끝난 뒤 10초에 OFF(문이 열린 동안과 주행 중에는 미룸)
- 음성: 학습 질문, 기억 확인, 「잠시만 기다려 주세요」, 처음 문이 열릴 때 신호 설명 한 번, 자세 예고 두 종류(「출발은/문은 '딩동' 뒤에」), 완료 세 종류, 「곧 도착해요」, 「자리를 원래대로 돌릴게요」
- 도착: 주행 중 기억한 장소 지오펜스 진입 시 부모님이 타고 있을 때만 "곧 도착해요" 한 번
- 오늘은 움직이지 않기(F7): 이동만 멈추고 학습·안내는 계속(앱이 살아 있는 동안)
- 보호자 도움: 앉는 순간 운전석이 비어 있고 비운 지 60초 이내면 빨리 앉아도 학습에 셈(「보호자님 도움」)
- 장소·시간대: 장소는 여러 곳(반경 200m), 느린 탑승을 요일·30분 칸으로 묶어 기준 횟수 이상이면 「알아본 시간대」
- 이번 탑승 확인: 확정 뒤 알아본 장소·시간대 밖에서 빨리 앉으면 「부모님 타셨어요?」로 묻고, 답이 아니요면 이번 정차는 자세를 바꾸지 않음
- 주행 중: P 를 벗어나면 예고·이동을 모두 멈추고 띠로 알림. 다음 P 에서 앉아 있으면 내릴 때 자세로, 빈 자리는 원위치를 예고 없이 이어감
- 내릴 때 자세: 등받이 세움 → 높이 → 쿠션 앞 내림 → 앞뒤 넓힘. 원위치는 축마다 반대로
- 열선: 확정 뒤 착좌 + 추움이면 2단, 하차 시 끔. 보호자가 끄면 이번 탑승엔 다시 켜지 않음
- 벨트: 맨 뒤에 가는 동안 자세를 시작하고, 도착 자세 뒤 풀면 「다리를 하나씩 내놓고…」 안내
